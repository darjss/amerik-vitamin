# Chat orders are created automatically, not drafted

A model watches mom's Messenger chats (main page, watch-only) and pilot-page handoffs. When a chat has a phone, an address, items and a clear yes, the model creates the order itself, with no confirm step. Mom types 30 to 40 chat orders a day, and a confirm tap for each would keep her as the bottleneck. This changes MANIFESTO law 8. It's safe because a new order starts as `new`, which moves no stock and no money. Every auto-created order says so, and Telegram shows it with a one-tap undo.
